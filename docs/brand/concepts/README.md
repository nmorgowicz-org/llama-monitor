# Local LLM Foundry logo concepts

These are exploratory raster concepts for selecting a Local LLM Foundry 2.0
logo direction. They are not production assets. The selected direction must be
redrawn as deterministic SVG geometry, checked at small sizes, reviewed for
visual similarity to existing marks, and expanded into monochrome, light/dark,
favicon, tray, installer, and release-artifact variants.

## 1. Forge Aperture

![Forge Aperture](01-forge-aperture.png)

A furnace arch containing a prompt chevron and ingot. It communicates the
foundry metaphor most directly, but needs simplification before it will survive
16 px rendering.

## 2. Token Ingot

![Token Ingot](02-token-ingot.png)

Model layers converge into a compact ingot. This is the recommended starting
direction: it connects model construction and foundry craft without relying on
a mascot. The SVG refinement should reduce generic database/download-icon
associations and remove all generated shading.

## 3. Local Core

![Local Core](03-local-core.png)

A protected local core inside a broken forge ring. It is compact and scalable,
but currently risks reading as a target, power control, or radiation-like mark.

## 4. LLF Monogram

![LLF Monogram](04-llf-monogram.png)

An interlocking LLF construction with an anvil-shaped base. It provides a
literal short-name route, but is less distinctive and visually heavier than the
symbol directions.

## Selection gate

Before promoting a concept, require:

- approval of one primary direction and one fallback;
- a hand-authored SVG master with no embedded raster data;
- one-color, dark-background, and light-background variants;
- legibility proofs at 16, 20, 24, 32, 64, 128, 256, 512, and 1024 px;
- macOS, Windows, Linux, browser favicon, tray, and compact-popover previews;
- a basic trademark and visual-similarity review;
- release-built UI screenshots showing the mark in real product surfaces.
