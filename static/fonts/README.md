# Bundled fonts

The application bundles the upstream webfont files below so typography does
not depend on a network request or a platform-installed font:

- Inter 4.1, from <https://github.com/rsms/inter/releases/tag/v4.1>
- Fira Code 6.2, from <https://github.com/tonsky/FiraCode/releases/tag/6.2>

Both font families are distributed under the SIL Open Font License 1.1. The
complete upstream notices are preserved in `LICENSE-Inter.txt` and
`LICENSE-Fira-Code.txt`. The WOFF2 files are unchanged upstream artifacts.
